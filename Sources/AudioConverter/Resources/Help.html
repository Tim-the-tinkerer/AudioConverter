Audio Converter Help

Convert audio between major formats using the FFmpeg engine embedded in this app. No separate FFmpeg install is required once the app is built.

Quick start

  1. Add files — drag audio files or folders onto the drop zone, or click Add Files.
  2. Choose output — pick a format and quality options in the right-hand panel.
  3. Set destination — save next to the original, or choose an output folder.
  4. Convert — click Convert (or press ⌘Return).

Each file is probed with the embedded ffprobe so you can see duration, codec, sample rate, and channels before converting. To rip a music CD, insert the disc and click Rip CD.

Working with the queue

  • Files appear in the Queue list with status badges: Pending, Ready, Converting, Done, or Failed.
  • While converting, a progress bar tracks FFmpeg’s reported position in the file.
  • Right-click a row to Show Source in Finder, Show Output in Finder (when done), or Remove.
  • Clear Finished removes completed, failed, and cancelled jobs.
  • Clear All empties the queue (not available while a conversion is running).
  • Folders are scanned recursively for known audio extensions.

Ripping an audio CD

Insert a music CD. macOS mounts it as a volume, one AIFF per track. Click Rip CD, or choose Convert → Rip Audio CD… (⌘R).

  1. Look up metadata — this runs on its own. MusicBrainz fills the artist, album, date, and track titles when it knows the disc. Edit anything that looks wrong. A disc that is not listed can still be ripped; type the names yourself and look up again.
  2. Choose tracks — uncheck any track you want to skip.
  3. Choose a folder — the default is Music/Audio Converter. Nothing is written onto the CD.
  4. Rip — each selected track is encoded with the format and quality in the sidebar. Files are named Artist - Album/01 - Title.flac (the extension follows the format you picked).

When the album matches, the front cover is downloaded from the Cover Art Archive and embedded as album art. That happens for MP3, M4A, M4B, ALAC, FLAC, and the other formats that can hold a picture. WAV and AIFF cannot. The other tags written are title, artist, album, album artist, date, and track number. Rip waits for that lookup to finish, so the picture is in the file even if you start immediately.

Eject when the rip finishes opens the drive only after every file in that batch succeeds. Add to Queue lists the tracks without starting. Dropping the CD’s volume on the window opens the same sheet.

If Combine is on, Rip joins the selected tracks into one file. For M4B, each track becomes a chapter.

Tracks are read through the audio CD volume macOS mounts. A scratched disc can still click or skip. MP3 CDs and other data discs are ordinary files — drop those on the window.

Supported formats

Reading (input)

Almost anything FFmpeg can decode, including: MP3 AAC / M4A FLAC WAV AIFF Ogg Opus WMA AC-3 CAF WavPack APE and many more. Video files with an audio track can also be used — only the audio stream is written.

Writing (output)

Format Notes
MP3 CBR or VBR via LAME. Great compatibility.
AAC (.aac / .m4a) Lossy; efficient for Apple devices and streaming.
M4B Audiobook AAC audiobook with chapter markers (Books / podcast apps).
ALAC Apple Lossless in an M4A container.
FLAC Lossless; adjustable compression level 0–12.
WAV / AIFF / CAF Uncompressed PCM (16/24/32-bit or float).
Ogg (Opus) Opus audio in an Ogg container (.ogg).
Opus / WebM Modern lossy; excellent quality at low bitrates.
WMA, AC-3, MP2, WavPack Additional legacy and specialty targets.

Stock Homebrew FFmpeg builds often omit libvorbis, so classic Ogg Vorbis is not used. Choose Ogg (Opus) or Opus instead.

Combine files (any format)

Turn on Combine queue into one file to join every item in the queue into a single output in the format you selected (MP3, FLAC, M4A, WAV, …).

  • Order is the queue order — drag rows or use Move Up / Move Down.
  • Mixed codecs, sample rates, and mono/stereo sources are normalized before joining.
  • FLAC, ALAC, and WavPack keep the widest bit depth in the queue, so a 24-bit master stays 24-bit. WAV, AIFF, and CAF use the PCM depth you pick. A file name that matches one of the sources is refused.
  • No chapter markers are written (continuous audio). For chapters, use M4B.
  • Optional title / artist / album / file name apply to the combined file.
  • Cover art is taken from the first source that has embedded artwork.

Chaptered M4B audiobooks

Choose M4B Audiobook (chapters) to build an audiobook for Apple Books and other M4B players.

Combine queue into one chaptered M4B

  1. Add one audio file per chapter (or drop a folder of tracks).
  2. Reorder chapters by dragging rows or using Move Up / Move Down in the context menu.
  3. Edit each chapter title inline (defaults come from the file name or title tag).
  4. Set Book title, Author, and optional album / file name in the sidebar.
  5. Click Create M4B — files are concatenated, encoded to AAC, and chapter markers are written.

Queue order = chapter order. Output is a single .m4b next to the first file (or in your chosen folder). Mixed formats (e.g. MP3 + M4A), sample rates, and mono/stereo chapters are supported — each file is normalized before joining.

Per-file M4B

Turn off Combine queue… to convert each source to its own .m4b. Enable Preserve chapters from source to keep markers already present in the file.

Output settings

Setting What it does
Format Target container and codec for every job in the next conversion run.
Bitrate Target kbps for lossy formats (e.g. 128–320 for MP3).
Variable bitrate (VBR) For MP3, enables LAME quality mode. For Opus-family formats, enables VBR mode while still using the bitrate target.
Joint stereo (MP3 VBR) When MP3 VBR is on, choose mid/side joint stereo (default, efficient) or simple stereo (independent L/R). Passed to LAME as -joint_stereo.
Sample rate Keep the source rate, or pick one. Combining uses 44.1 kHz unless you pick another rate. Opus, Ogg (Opus), and WebM (Opus) default to 48 kHz and only list rates those encoders accept: 8, 12, 16, 24, and 48 kHz.
Channels Keep source layout, or force mono / stereo.
PCM / FLAC options Bit depth for WAV/AIFF/CAF; compression level for FLAC.
Save next to original When on, writes Song.ext beside the source. When off, uses the chosen output folder.
Overwrite existing If off, conversion fails when the destination file already exists. If on, the new file replaces that destination only after encoding succeeds. A failed or cancelled conversion leaves the existing file in place.
Copy metadata When on, tags (title, artist, album, …) are mapped from the source when the container supports them.
Embedded artwork Always preserved when the destination supports it (MP3, M4A/M4B, ALAC, FLAC, and others). Cover art is extracted from the source and re-attached as an album picture. Queue rows show Art when a cover is detected. WAV/AIFF/raw AAC cannot store cover art.

Settings are applied when you start conversion. Change them between batches as needed. A destination that matches any file in the queue is refused, including a combined file named like one of its own inputs. Pick another name or folder.

Embedded FFmpeg

At build time, build-app.sh copies ffmpeg, ffprobe, and their libraries into the app bundle (Contents/MacOS and Contents/Frameworks).

  • The status line and Settings window show whether FFmpeg is embedded, from the system, or missing.
  • Open Audio Converter → Settings… to see the full version string and recheck availability.
  • The embedded build is FFmpeg 9.1, produced by scripts/build-ffmpeg.sh. Homebrew’s own formula may be older. If FFmpeg is missing, run that script, then ./build-app.sh.

Troubleshooting

Problem What to try
FFmpeg not found Run ./build-app.sh from the project folder. Requires brew install ffmpeg at build time only.
File shows Failed after probe The file may be corrupt, DRM-protected, or not an audio stream FFmpeg can open. Try another source copy.
Conversion failed / unknown encoder Your embedded FFmpeg build may lack that encoder. Prefer MP3, AAC, FLAC, Opus, WAV, or ALAC.
Output already exists Enable Overwrite existing files, or change format / destination folder.
Source and output are the same You chose the same extension as the source with “save next to original”. Pick another format or an output folder.
Rip CD shows no disc Wait until the CD appears in Finder, then click Refresh. It has to be a music CD in an internal or USB drive. A data CD is not listed here.
MusicBrainz has no entry Type the artist, album, and track titles, then click Look Up Metadata again. A title search can still find the cover. The rip does not need a lookup.
Ripped files have no album art The sheet says when a cover was found. WAV and AIFF cannot store a picture — choose MP3, M4A, FLAC, or ALAC. If the message says no cover art, the Cover Art Archive has no front image for that release.
A track fails while ripping Clean the disc. Quit Music if it is using the drive, remove the failed row, and rip that track again.
App won’t open (Gatekeeper) Right-click the app → Open, or run xattr -cr AudioConverter.app.
